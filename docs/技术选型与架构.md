# 技术选型与架构 (Tech Stack & Architecture)

## 1. 核心架构决策
**项目定位**：全能算术：幻影行者 (Phantom Math)
**目标平台**：PWA (Progressive Web App) - 优先适配移动端，兼容桌面端。

---

## 2. 技术栈清单 (The Stack)

### 2.1 运行环境与构建 (Runtime & Build)
*   **Runtime & Bundler:** **Bun**
    *   *理由：* 极致的启动速度和打包性能，统一包管理、测试和构建工具。不使用 Vite 或 Webpack，直接使用 `bun build`。
    *   *指令：* `bun install`, `bun run dev`, `bun build`

### 2.2 前端框架 (Frontend Core)
*   **Framework:** **React** (SPA Mode)
    *   *理由：* 生态成熟，配合 Framer Motion 实现复杂交互。
*   **Language:** **TypeScript**
    *   *理由：* 强类型约束，不仅为了代码安全，更为了清晰描述“战斗系统”和“卡牌数据”的复杂结构。

### 2.3 视觉与样式 (Visual & Styling)
*   **Styling Engine:** **Tailwind CSS (Pure)**
    *   *决策点：* **拒绝组件库 (No DaisyUI/MUI/AntD)**。
    *   *理由：* P5 风格（极繁主义、锯齿、梯形、拼贴）与常规 UI 组件库的圆角/规整风格严重冲突。直接使用 Tailwind 原子类配合 `clip-path` 自定义形状效率最高。
*   **Animation:** **Framer Motion**
    *   *理由：* 整个应用的灵魂。用于实现“界面破碎”、“卡牌飞入”、“数字跳动”等复杂编排动画。
*   **Charts:** **ApexCharts**
    *   *理由：* 用于“学力雷达图”绘制，轻量且支持深色模式定制。
*   **Icons:** **Heroicons** (基础功能) + **Inline SVG** (装饰性图标)

### 2.4 状态管理 (State Management)
*   **Store:** **Zustand**
    *   *理由：* 轻量、无样板代码。非常适合分离 `UserStore`（全局设置）和 `BattleStore`（瞬时战斗状态）。
*   **Persistence:** `zustand/middleware/persist` (用于本地存储用户数据)

### 2.5 平台能力 (Platform Capabilities)
*   **PWA:**
    *   **Manifest:** 实现“添加到主屏幕”，全屏沉浸式体验 (`display: standalone`)。
    *   **Service Worker:** 缓存字体、图片和核心逻辑，实现离线刷题。
*   **Storage:** **IndexedDB / LocalStorage**
    *   *理由：* 本地优先策略，所有游戏进度保存在用户设备上。

## 3. 项目结构规范
```text
src/
  components/
    ui/                # 原子组件 (JaggedButton, TrapezoidCard)
    daytime/           # 表世界业务组件
    nighttime/         # 里世界业务组件
  features/            # 核心逻辑模块
    battle/            # 战斗系统逻辑 (非 UI)
    gacha/             # 抽卡逻辑
  store/               # Zustand 状态
  assets/              # 静态资源
```
