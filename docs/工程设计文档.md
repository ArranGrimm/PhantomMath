# **详细设计文档：全能算术 (Phantom Math) - React MVP 版**

技术栈： React + Tailwind CSS + Framer Motion (推荐) + Zustand (状态管理)

主题设定： 上海地铁（日常表世界） vs 认知迷宫（战斗里世界）

---

## **2. 详细视图设计 (View Specifications)**

### **2.1 视图 A：启动页 (Splash Screen)**

* **视觉：** 全红背景，中间是黑白剪影风格的 LOGO（比如一只戴着面具的猫头鹰）。  
* **元素：**  
  * Logo: 居中，带有故障 (Glitch) 动画。  
  * StartButton: 文本 "TAKE YOUR HEART"，点击后像玻璃破碎一样转场。  
* **功能：** 初始化用户数据，加载资源。

### **2.2 视图 B：表世界主页 (Daytime Hub)**

* **场景：** **上海地铁 2 号线车厢**。背景是移动的车窗风景（陆家嘴高楼剪影）。  
* **核心 UI：主角的智能手机 (Smartphone Menu)**  
  1. UI 位于屏幕右下角，倾斜显示，模仿 P5 的 IM 界面。  
* **菜单选项 (Buttons)：**  
  1. **委托 (Requests):** 红色角标显示今日剩余题数。点击 -> View C。  
  2. **通缉 (Wanted):** 骷髅头图标，显示错题数。点击 -> View D。  
  3. **异世界 (MetaNav):** 一个画风诡异的红黑眼睛图标。点击 -> 触发转场动画 -> View F。  
  4. **我的 (Stats):** 学生证图标。点击 -> Overlay Profile。

### **2.3 视图 C：每日委托 (Daily Requests)**

* **场景：** **手机短信界面**。
* **布局：**
  * Header: 联系人 "Shadow Operative" (影子特工)。
  * **Mission Zone:** 
      * **计算题:** 气泡显示 "目标确认：25 + 13 = ?"。
      * **逻辑题:** 嵌入对应的 Mini-Game 组件 (如排队图示、密码锁面板)。
  * InputArea: 
      * 计算题：底部弹出 P5 风格数字键盘。
      * 逻辑题：直接在题目区域交互 (点击/拖拽)。
* **交互：**
  * 用户输入答案 -> 点击发送。
  * **正确：** 气泡变绿，获得金币 + 对应数字卡 (Answer cards)。
  * **错误：** 气泡破碎，屏幕闪红 -> 加入错题通缉令。

### **2.4 视图 D：错题通缉令 (Wanted Board)**

* **场景：** **地铁站台的广告墙**。
* **布局：**
  * Wall: 背景是瓷砖墙。
  * Posters: 每一张海报代表一道错题。海报是红黑色的，印着错误的算式和 "WANTED" 字样。
* **交互：**
  * 点击海报 -> 弹出订正窗口。
  * 订正正确 -> 播放 **撕纸动画**，海报消失，获得 "心之秘钥" (Key)。

### **2.5 视图 F：里世界主页 (Metaverse Hub)**

* **场景：** **扭曲的红色虚空**。背景是不断旋转的放射状线条。
* **核心 UI：3D 环形菜单** (可以用 2D 模拟)
* **菜单选项：**
  1. **INFILTRATE (潜入):** 巨大的中心按钮。消耗 Key -> 进入 View G (战斗)。
  2. **PERSONA (面具):** 查看卡组。
  3. **VELVET (天鹅绒):** 监狱铁门图标。消耗金币 -> 进入 View H (抽卡)。
  4. **RETURN (返回):** 回到表世界。

### **2.6 视图 G：战斗界面 (The Arena - 核心中的核心)**

* **布局结构：**
  * **上部 (Enemy Zone):**
    * MonsterSprite: 剪影风格怪物。
    * HPBar: 很长、带有锯齿边缘的血条。
    * Condition: 显示 "BLOCK < 10" (防御条件)。
  * **中部 (Chamber Zone):**
    * Slots: 5-7 个空的卡槽（类似填字游戏格），这是放置算式的地方。
    * ResultPreview: 实时显示当前拼出的算式结果 (e.g., "Total: 45")。
  * **下部 (Hand Zone):**
    * Deck: 扇形排列的手牌 (数字牌 + 符号牌)。
  * **侧边 (Buff Zone):**
    * PersonaCard: 悬浮在左侧，当条件满足时（如用了乘法），头像亮起并喷射火焰。
* **功能：**
  * 拖拽手牌到 Slot。
  * 点击 "FIRE" 按钮 -> 结算伤害 -> 播放攻击特效。

### **2.7 视图 H：天鹅绒房间 (Gacha)**

* **场景：** **监狱牢房**。
* **交互：**
  * GachaBtn: 一个巨大的断头台拉索。
  * 拉动 -> 动画播放（断头台落下）-> 屏幕闪白 -> 展示新获得的 Persona 卡牌。

## **3. 数据结构设计 (Data Schema)**

### **3.1 全局用户状态 (UserStore)**

```typescript
interface UserState {
  // 资源
  coins: number;      // 认知金币
  keys: number;       // 心之秘钥
  
  // 进度
  infiltrationProgress: number; // 潜入进度 (0-100%)
  dailyMissionCompleted: boolean;
  
  // 核心数据
  wrongQuestions: Question[]; // 错题队列
  inventory: {
    ammoCards: string[];      // 数字/符号卡 (e.g. ['1', '9', '+', 'x'])
    personas: Persona[];      // 拥有的人格面具
  };
}
```

### **3.2 战斗状态 (BattleStore)**

```typescript
interface BattleState {
  // 敌方
  monster: {
    hp: number;
    maxHp: number;
    weakness?: string; // e.g. "OddNumber" (奇数伤害加倍)
  };
    
  // 我方
  hand: Card[];        // 当前手牌
  slots: Card[];       // 算式槽中的牌 (长度5-7)
  equippedPersonas: Persona[]; // 携带的Buff卡
    
  // 逻辑
  currentEquation: string; // e.g. "5 * 8 + 2"
  previewDamage: number;   // 实时计算的伤害值
}
```

### **3.3 题库系统设计 (Math Engine - NEW)**

为了支持无限生成和多类型题目，我们设计一个名为 `QuestionGenerator` 的工厂系统。

```typescript
// 题目类型
enum QuestionType {
  CALCULATION = 'CALCULATION',   // 基础计算
  LOGIC_QUEUE = 'LOGIC_QUEUE',   // 排队问题
  ALGEBRA_SHAPE = 'ALGEBRA_SHAPE', // 图形代数
  SPATIAL_CUBE = 'SPATIAL_CUBE',   // 空间方块
  MATCHSTICK = 'MATCHSTICK',       // 火柴棒
}

interface Question {
  id: string;
  type: QuestionType;
  difficulty: 1 | 2 | 3 | 4 | 5;
  
  // 题干 (支持富文本)
  text: string; 
  
  // 视觉渲染数据 (根据类型不同而不同)
  visualData?: {
    queue?: { total: number, targetIndex: number, direction: 'left' | 'right' };
    cubes?: { matrix: boolean[][][] }; // 3D矩阵
    matchstick?: { equation: string }; 
  };

  // 验证逻辑
  validate: (input: any) => boolean;
  
  // 奖励预测
  rewards: {
    coins: number;
    cards: string[]; // 预计算的产出卡牌
  };
}
```
